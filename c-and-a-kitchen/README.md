# C&A's Kitchen - AWS Cloud Engineering Project

## Project Description

C&A's Kitchen is a simple food business website created as a cloud engineering practice project.

The application will eventually be deployed to AWS.

## Project Goals

The main goal of this project is to practice:

- Linux
- Git
- GitHub
- AWS
- AWS EC2
- AWS CLI
- SSH
- Nginx
- Bash scripting
- Docker
- Cloud networking
- Cloud monitoring

## Technologies

- HTML
- CSS
- JavaScript
- Linux/Ubuntu
- Git
- GitHub
- AWS

## Planned AWS Architecture

The website will be deployed to an AWS EC2 instance.

User -> Internet -> AWS EC2 -> Ubuntu -> Nginx -> C&A's Kitchen Website

## Deployment Plan

1. Build the website
2. Test locally
3. Create GitHub repository
4. Push project to GitHub
5. Create AWS EC2 instance
6. Connect to EC2 using SSH
7. Install Nginx
8. Deploy website
9. Configure security groups
10. Add monitoring
11. Add backup
12. Containerize with Docker
